# Security and abuse

## Reporting a vulnerability

Please report security issues privately through GitHub's "Report a vulnerability" (Security tab), not in public
issues. You will get a reply within a few days, and fixes ship as patch releases.

## Rights holders and takedown requests

tubepull is a general-purpose tool and hosts no content. If you believe this project infringes your rights,
contact the maintainer through the repository's Security tab or the email on the npm package, and the request
will be handled promptly.
